# 课程后台槽位与共用讲师

微信小店课程包采用 platform_profile: wechat_course。根据2026-10-14用户后台截图，方图与竖图是独立位置；默认兼备，不能互相替代。各商品 assets 用 slot 标记 main_1_1、main_3_4、instructor、course_outline；课程大纲必须是可上传图片，HTML不能代替。标记可以加在已有资产上，不强制重复拷贝。后台新证据改变要求时保存spec_source并更新验证配置，不能靠漏填profile逃过检查。非课程商品仍使用原检查。

## 讲师复用
读取本机 local-vault.json 中的 instructor_library；在OB共用目录维护公开介绍图、reusable-profile.json和来源档案。位置取自本机配置。资料未就绪时如实记录缺口，不生成真人或编造履历。已确认图片复制到每个商品03-商品资质/01-讲师介绍/01-讲师介绍.png，并记录sha256、source_ref、real_portrait_verified、public_name_verified、facts_verified。四项核验必须来自实际查看与本人确认；文件检查无法证明真实身份。保留复用主档，课程大纲每商品分别匹配。

## 目录与检查
按 listing-workflow.md 建立03-商品资质与04-商品展示与介绍/03-3比4主图；入口按后台槽位显示上传文件。主图比例用像素尺寸校验；资质图片采用PNG/JPEG/BMP、单张不超过10MB（当前截图规格）。公开介绍图与非公开学历证件分开，证件不进入公开素材包。没有真实照片、公开姓名或履历确认时，完整性检查失败并报告具体缺项，继续完成其他文件。视频在当前截图未显示必填，本轮不以视频缺失阻断；后续按实际类目验证。

## 详情图与价值表达
主图、商品详情图、商品资质是后台不同上传项。当前后台提示详情图至少1张，建议3张以上且避免与主图重复；默认制作3张独立详情图，分别解释方法体系、工具/服务内容、使用路径与成果。入口必须明确标注上传栏目，并展示图片及可复制完整路径。不能把资质大纲或轮播图数量当成详情图已上传。

工具型课程从真实交付梳理“方法论＋工具套装＋实际成果”。总入口不等于只有一个Skill；存在可独立用的子Skill时展示真实结构、应用范围和复用方式，不把随包工具能力都写成已完成课程，不把获得工具等同自动掌握方法。

完整大纲必须按[课程大纲制作标准](course-outline-template.md)整理，成果总览图不能替代详细大纲。

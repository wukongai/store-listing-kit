# 微信小店上架助手｜安装与使用手册

[布丁阅读入口](https://aixiaoai.cloud/cases/cmv9zjvpj001epo4djz75wlj1)


要上架一个商品，却还要准备主图、详情海报、介绍文案和交付文件？这个小店 Skill 把这些工作串起来，最后给你一份可以按顺序操作的 HTML 交接清单。

## 一次安装，两个 Skill 配合

你可以把下面这段话完整发给 Codex 或 Claude Code 等支持 Skill 的 Agent：

```text
请安装 store-listing-kit：
npx skills add wukongai/store-listing-kit --skill store-listing-kit

同时检查 image-factory：已有可用版本就复用，不覆盖；没有则安装配套的简易公开版：
npx skills add wukongai/image-factory-public --skill image-factory

安装到当前项目，检查两个 Skill 的完整文件与依赖。然后确认是否有实际生图能力；有就继续，没有就引导我在本地配置自己的 API Key，不要让我把 Key 发到聊天里。
```

小店 Skill 负责整体流程，图片工厂负责主图、详情图和营销海报。安装后只需要调用小店 Skill，它会检查图片工厂，缺少时按你的安装授权补齐，再调用它制作图片；不用每次手动切换两个 Skill。已有同名私人版本时优先复用，不能直接覆盖。

需要 Node.js/npx、Python 3.10+。让 Agent 在项目虚拟环境安装所需 Python 依赖；不能执行命令的纯聊天工具无法完成本地安装。

## 开始做一个商品

把产品资料和后台截图准备好，再对 Agent 说：

```text
使用 store-listing-kit，帮我准备这个商品的上架素材。
产品资料：[文件路径]
后台要求：[截图或字段清单]
我的知识库与产品目录：[路径]

先整理资料包和 todo list，缺少真实信息时问我。
图片任务自动交给 image-factory，整套风格一致。
文字、图片、交付文件完成后，生成一个 HTML 交接清单。
请实际检查文件与图片，不要把提示词或计划当成已完成素材。
```

按 Agent 提示确认商品名称、人群、卖点、价格及交付范围。没有的评价、资质、肖像不要编造；不确定的交易信息先保留待补。

## 最后拿到什么

- 主图和详情海报：以实际后台尺寸、数量要求为准。
- 可复制的名称、简介、详情和客服说明。
- 数字产品的实际交付文件，或服务/实物的履约说明。
- **HTML 交接清单**：按后台栏目排序，预览图片、复制文案和文件路径、逐项勾选。打开这一页即可操作，不用逐层找文件夹。

公开版负责准备素材和交接清单，不负责登录你的店铺或自动发布商品。

## 关于配套图片工厂

这里提供的是我图片工厂的**简易公开版，重点保留商品营销海报能力**，不是我的完整私人工作台。包括方形主图、竖版详情、参考图改版，以及黑底赛博大字、黑白大字、橙色营销、奶油质感等模板。

你可以在这个基础上增加自己的品牌、模板和风格；它不包含我的私人 IP、API Key 或免费生图额度。图片生成使用你自己的 Agent 工具或 API 账号。

配套说明：[图片工厂简易公开版手册](https://aixiaoai.cloud/cases/cmv9zjeip001dpo4d6w4xgqgi)。

## 遇到问题

只有提示词、没有图片：说明实际生图工具尚未接通，打开配套图片工厂手册完成接入。安装后没识别到 Skill：让 Agent 重新扫描当前项目的 Skill，必要时重开会话。已有成品需要重做：保存旧版，另建新版本，避免覆盖。
